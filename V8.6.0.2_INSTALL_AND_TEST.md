# Workday Journey V8.6.0.2 - UI Startup & Personalization

## Install
1. Back up your existing V8.6.0.1 project.
2. Copy the changed files from the ZIP into the **project root**, overwriting existing files. Keep your existing data and configuration files.
3. Reload with Ctrl+Shift+R once, or use the in-app Reload Latest Version action.
4. **No SQL is needed.** This is a presentation/settings release; Economy and Bank operations are unchanged.

## What's new (user-facing)
- Smoother first display: a brief branded startup screen hides legacy UI while the current layout initializes.
- Choose **UI Size**: Small / Default / Large (independent of Font Size).
- Choose **Icon Style**: Modern (line) / Classic (emoji) for sidebar, topbar, page headings, and mobile dock.
- **Layout Density**: Compact / Comfortable / Spacious.
- Appearance preferences are saved and can follow a signed-in account via the app's existing settings synchronization.
- **What's New** now contains a concise, nontechnical timeline of major features instead of every patch.

## Test checklist
- Reload on desktop and mobile; check that old icons/old shell are not shown before the current UI.
- Settings > Appearance: change UI Size and Icon Style, refresh, confirm persistence.
- Check both the main Settings page and the advanced settings drawer; ensure the two controls agree.
- Switch TH/EN; option labels and help text should translate.
- Switch Layout Density to Spacious; make sure controls/cards have more breathing room.
- Confirm that existing Font Size settings still work independently.
- Check Light/Dark and narrow mobile screens.
- Open What's New: only major releases/short highlights should appear.
- Verify Login, Bank and other account actions on your deployed site (not exercised against live services here).

## Notes
- This package contains only modified/new files; do not remove files absent from the archive.
- The full production app and account services were **not** tested here. Static checks and an isolated browser DOM test passed. Test on the deployed site after installing.
- If the app is offline with an older PWA cache, reconnect and use Reload Latest Version to install the new assets.
