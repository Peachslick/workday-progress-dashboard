# Workday Journey V8.5.5 — Final Polish & Responsive QA

## Installation
1. Keep your existing V8.5.4 project as-is and make a backup.
2. Extract this changed-files-only archive directly over the project root (same level as index.html).
3. Restart local web server as usual and reload (Ctrl+Shift+R if the PWA still shows the old release).
4. No Supabase SQL migration is required.

## What changed
- V8.5.5 polish CSS: responsive layouts at narrow widths, scrollable tabs, touch targets, dark-mode contrast, keyboard focus, readable existing empty/loading states, constrained modals, reduced motion.
- V8.5.5 helper JS: skip-to-content keyboard link, back-to-top for long pages, localized Finance tab labels when changing TH/EN, descriptive watchlist controls, focus containment for visible dialogs, existing in-flight button busy indication, consistent version labels.
- What's New: Thai/English V8.5.5 summary added to the top of Patch History.
- PWA: cache revision v8.5.5 and scope-limited removal of old Workday Journey caches.

## Scope & limitations
- Presentation and accessibility changes only: no Coin, Shop, Trading, Work Bank, Reward Code, Auth, SQL or Supabase rules modified.
- Browser fixture tests do not exercise real Supabase logins, cloud upload, server-side payments, or live Exchange trades; please test those separately against your own environment.
- Manual smoke tests after installing: visit Dashboard, Journal, Projects, Calendar, Reports, Achievements, Missions, Reward Shop, Bank and Exchange at 320px, 390px, 768px and desktop sizes. Check TH/EN, light/dark mode, Finance tabs, modal scrolling, keyboard Tab/Shift+Tab, save/edit flows, and refresh after PWA update.
