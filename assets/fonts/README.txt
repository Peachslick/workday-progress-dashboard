Sarabun local font folder
=========================

Run ../../setup-sarabun-font.bat once while internet is available.
The setup downloads these files from the official Google Fonts repository:
- Sarabun-Regular.ttf
- Sarabun-Medium.ttf
- Sarabun-SemiBold.ttf
- Sarabun-Bold.ttf
- Sarabun-ExtraBold.ttf
- OFL.txt

After setup, the dashboard uses these local files and can be opened offline.
